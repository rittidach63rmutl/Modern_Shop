# Modern Shop

A modern E-Commerce web application built with PHP, MySQL, and Tailwind CSS.

## Features
- Storefront with product browsing, categories, and shopping cart
- User authentication and role-based access (Admin/User)
- Admin dashboard to manage products and view orders
- Automatic database setup and seeding
- Responsive design with mobile hamburger menu

## Setup
1. Clone the repository.
2. Ensure you are running a local server like XAMPP (Apache + PHP + MySQL).
3. Place the project folder in `htdocs`.
4. Open the project in your browser. The database `modern_shop_db` and tables will be created automatically.
